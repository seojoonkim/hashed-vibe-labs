# Hashed Vibe Labs

> Where vibes become rocket products.

Official website for [Hashed Vibe Labs](https://vibelabs.hashed.com) — an 8-week program that discovers AI-native founders at the earliest stage, invests immediately upon selection, and supports their journey with Hashed's global network.

## Features

- Terminal-style interactive UI with command navigation
- Bilingual support (Korean / English) with auto-detection
- Section-by-section content delivery with loading animations
- Real-time application deadline countdown
- Fully responsive (desktop + mobile)

## Tech Stack

Next.js 14 · React 18 · TypeScript · Tailwind CSS · Framer Motion

## Getting Started

```bash
npm install
npm run dev
```
